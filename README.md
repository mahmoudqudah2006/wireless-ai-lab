# Wireless AI Lab

A reproducible playground for applying **machine learning to wireless communication problems**. The first release focuses on synthetic link-budget data, link-quality features, and modulation-selection baselines that can be inspected before moving to deeper models.

This repository is the umbrella AI/wireless project in the portfolio. More specialized work lives in `rl-link-adaptation` and `gnn-wireless-network-optimizer`.

## Current experiment

A synthetic point-to-point link dataset is generated from:

- transmitter–receiver distance
- transmit power
- log-distance path loss
- log-normal shadowing
- receiver noise floor
- resulting SNR

The supervised target is a transparent SNR-threshold modulation policy:

| SNR | Class |
|---:|---|
| < 4 dB | BPSK |
| 4–10 dB | QPSK |
| 10–18 dB | 16-QAM |
| >= 18 dB | 64-QAM |

This target is deliberately simple: the goal of the baseline is to validate the data/ML pipeline. Later versions can replace it with labels generated by BLER curves, link simulations, or measured data.

## Features

- reproducible synthetic link dataset generation
- log-distance path loss + shadowing model
- explicit feature/label schema
- Random Forest modulation classifier
- train/test evaluation
- feature importance export
- confusion-matrix-ready predictions
- CLI, tests, and CI

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'

wireless-ai train --samples 10000 --seed 7 --output results/baseline.json
```

## Example output

The result JSON contains model accuracy, class names, feature importances, and train/test sample counts. No performance number is hard-coded in this README because metrics should come from the actual run and software environment.
